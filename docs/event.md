# Event notes

Source: participant guide pasted by a teammate on 13 November 2026, with schedule cross-checks against the [public event website](https://2026.hackjunction.com/). This is a working summary, not the full official guide. Check Junction Platform and Discord announcements for changes.

## Where and when

- Junction 2026: European Tech Renaissance, 13-15 November.
- Hype Areena, Vanha Jorvaksentie 3, 02320 Espoo, Finland.
- Use Europe/Helsinki for deadlines, UTC+02:00 during this event.
- Registration is individual: valid ID, dashboard QR code and visible badge.
- The venue permits overnight access, but the guide says sleeping there is not allowed.
- Junction Platform handles teams, partner meetings, submissions and reviews. Discord carries announcements and mentor discussions.

## Rules affecting the project

- Team size: 1-4. MUSTA HELMI plans four members.
- Enter at least one challenge. Multiple challenges are allowed; the preliminary choice can change.
- No advance project code. Apart from open-source libraries, project code must be written at the event. The guide also excludes advance idea-specific code and projects tied to an existing company as described in its rules.
- The guide requires MIT-licensed submissions and source access for organizers. Partner APIs and materials retain their own terms.
- Every participant must take part in assigned live peer reviews for main-prize eligibility.
- Challenge partners choose their track winners. Peer review determines the top five, followed by stage pitches and judge voting.
- General criteria: innovation, impact and implementation. Each partner can add specific criteria.

## Conflicts and open questions

- Peer review ends at 13:00 in the schedule and 14:00 in the guide's reviewing section. Keep the team available through 14:00 until clarified.
- Friday's draft deadline precedes Saturday's submission opening. Treat preliminary submission as a separate action and check the dashboard flow.
- Meal times differ across guide sections. Use current venue announcements.
- The pasted guide says workshops need no sign-up; the public Cala workshop text says to sign up early. Confirm at the workshop/Discord.
- Pre-event treatment of custom agent skills and generic configuration is not explained. These repository files document working procedures; they are not product code or proof of organizer approval.
