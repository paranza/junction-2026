# Submission checklist

Source: participant guide supplied on 13 November 2026. Check the live form for updated requirements. All times below are Europe/Helsinki.

Submission owner: **Unassigned**. Backup: **Unassigned**.

## Preliminary submission

- [ ] All four teammates have joined MUSTA HELMI on Junction Platform.
- [ ] Submit the preliminary draft/intended challenge by Friday 13 November, 23:59.
- [ ] Record confirmation privately. The guide allows changing the challenge later.

## Required final fields

- [ ] Project name.
- [ ] Punchline.
- [ ] Description explaining the problem, user and working result.
- [ ] At least one challenge selected; additional entries checked against their criteria.
- [ ] Technologies used.
- [ ] Publicly viewable video, **at most 2:00**. Suggested target: 1:50-1:55 to leave encoding margin.
- [ ] Working demo link.
- [ ] Source-code link accessible to organizers.
- [ ] Source-code publicity selection completed.
- [ ] Attribution preference completed.
- [ ] Pitch deck uploaded as PDF.
- [ ] Team members' phone numbers entered privately in the platform.
- [ ] Discord username entered for backup contact.
- [ ] MIT license included for team code; third-party notices/data terms respected.

## Final checks

- [ ] Open the video and demo in a signed-out browser and verify intended access.
- [ ] Confirm organizer access to the source; do not assume a private repository link is enough.
- [ ] Verify the actual encoded video duration, not just the script's estimated length.
- [ ] Check the PDF opens and contains the final pitch.
- [ ] Check for accidentally committed secrets and private contact details.
- [ ] Ensure demo claims match implemented behavior; identify fixtures or mocks clearly.
- [ ] Set the submission to **FINAL**, not DRAFT, before Sunday 15 November at 10:00.
- [ ] Save confirmation privately and have the backup verify it.

Suggested internal target: Sunday **09:00**, leaving an hour for upload/access failures. The official form closes at **10:00**, with no late submissions. The guide says even FINAL submissions can be edited before the deadline.

## Peer review and stage

- [ ] Every teammate is present for assigned live peer reviewing from 10:30 on Sunday.
- [ ] Keep availability through 14:00 until the conflicting end times are clarified.
- [ ] Keep the assigned table staffed according to organizer instructions.
- [ ] Rehearse a three-minute stage pitch and three-minute question period before peer review.
- [ ] Check the demo laptop's display connection and keep contact channels available.

Do not check a box based on intent. Record observed completion. This checklist does not submit the project automatically.
