# Demo check

Read [demo plan](../../../docs/demo.md) and [submission requirements](../../../docs/submission.md). Paths are relative to this skill directory.

Run the selected user flow from a known state on the intended demo environment. Confirm the result, external service access and remaining credit where visible. Report missing access rather than assuming it. Identify any fixture, mock or recording used as a fallback.

For a submission video, measure the final file's duration if available; the maximum is 2:00. If only a script exists, label timing as an estimate. Check public access and avoid exposing secrets.

For the stage, time a separate 3:00 pitch and prepare for 3:00 of questions. Keep the demonstrated result linked to the user problem and judging criteria. Report blockers with concrete remedies. Uploads, publication and external edits require authorization from the current task.
