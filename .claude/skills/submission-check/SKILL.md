# Submission check

Read [submission checklist](../../../docs/submission.md) and [event notes](../../../docs/event.md). Paths are relative to this skill directory. Compare with the current official form when accessible; flag differences.

Check each required field and artifact against observable evidence. Verify video duration, public viewing, demo access, organizer source access, PDF readability and the licensing entry. Keep team contact values in the private submission system.

Use Europe/Helsinki for the Friday 23:59 preliminary and Sunday 10:00 final deadlines. A draft is not eligible for review. Distinguish prepared materials, saved form, FINAL status and a confirmed submission. Mark unobservable items as unverified.

Return missing items, owners if known and the next action. Preserve the guide's unresolved peer-review end-time conflict and all-member participation requirement. This skill does not authorize submitting or changing the remote form; do so only if the user explicitly requests that action, and verify the resulting status.
